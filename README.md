# Amazon Clone Backend (Spring Boot)

This is a fully functional backend project built for the Scaler Capstone (Neovarsity + Woolf).

## Features
- User Signup/Login (JWT)
- Product Management
- Category Management
- Cart Management
- Order Placement
- Payment Simulation (Mock)
- Spring Security + JWT Auth
- MySQL Database
- Service + Repository Layered Architecture

## Tech Stack
- Java 17
- Spring Boot 3
- Spring Security
- MySQL
- JPA / Hibernate
- JWT

1. Install MySQL
